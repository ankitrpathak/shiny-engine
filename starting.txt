================================================================================
🚗✨ ON-DEMAND CAR WASH PLATFORM - SIMPLE STEP-BY-STEP STARTUP GUIDE
================================================================================
This guide is written in plain, simple English so that ANYONE can extract this
project on any laptop and run the entire platform smoothly for demonstrations.
================================================================================

--------------------------------------------------------------------------------
STEP 1: CHECK 3 PREREQUISITES (Takes 1 minute)
--------------------------------------------------------------------------------
Before starting, open "Command Prompt" (cmd) or PowerShell and verify you have:

1. Java 21 (or later)
   Type:   java -version
   Check:  Should display version 21 (e.g., java version "21.0.6")

2. Apache Maven (3.9+)
   Type:   mvn -version
   Check:  Should display Apache Maven 3.9.x

3. Node.js & npm (v20 or v22)
   Type:   node -v
   Type:   npm -v
   Check:  Should display v20.x or v22.x

*NOTE: You DO NOT need to install or configure any database! All microservices
come with a zero-config in-memory database (H2) that seeds sample data, default
users, wash packages, and demo reviews automatically on startup.*


--------------------------------------------------------------------------------
STEP 2: HOW TO START THE PLATFORM (EASIEST 1-CLICK METHOD)
--------------------------------------------------------------------------------
In the extracted project folder, we have created two double-clickable scripts:

1. Double-click "start-backend.bat"
   - It will open separate terminal windows for all 8 microservices in the
     correct order (Eureka Server first, then Gateway, then all services).
   - Wait about 30-40 seconds for all services to start and register.

2. Double-click "start-frontend.bat"
   - It will install frontend dependencies if needed and start the Angular
     server on http://localhost:4200.

3. Open your browser and go to:
   👉 http://localhost:4200


--------------------------------------------------------------------------------
STEP 3: ALTERNATIVE MANUAL STARTUP (If corporate laptop blocks .bat files)
--------------------------------------------------------------------------------
If your corporate laptop restricts double-clicking .bat files, simply open
separate terminal/command prompt tabs and run these commands:

[Terminal 1 - Service Registry]
   cd eureka-server
   mvn spring-boot:run
   (Wait 10 seconds before starting the next)

[Terminal 2 - API Gateway]
   cd api-gateway
   mvn spring-boot:run

[Terminal 3 - User Service]
   cd OnDemandCarWash-user-service
   mvn spring-boot:run

[Terminal 4 - Booking Service]
   cd OnDemandCarWash-booking-service
   mvn spring-boot:run

[Terminal 5 - Payment Service]
   cd OnDemandCarWash-payment-service
   mvn spring-boot:run

[Terminal 6 - Review Service]
   cd OnDemandCarWash-review-service
   mvn spring-boot:run

[Terminal 7 - Notification Service]
   cd OnDemandCarWash-notification-service
   mvn spring-boot:run

[Terminal 8 - Admin Service]
   cd adminservice
   mvn spring-boot:run

[Terminal 9 - Frontend Web App]
   cd Frontend\odc-frontend
   npm install
   npm start
   (Then open http://localhost:4200)

--------------------------------------------------------------------------------
STEP 7: SIMPLE TROUBLESHOOTING
--------------------------------------------------------------------------------
Q: Port is already in use (e.g., port 8080 or 8081):
   - Make sure no older instances or Docker containers are occupying the port.
   - In cmd run: `netstat -ano | findstr :8080` then kill the PID with `taskkill /F /PID <PID>`.

Q: Node/npm install gives permission errors on corporate laptop:
   - Open Command Prompt as Administrator, or run `npm install --no-audit` inside
     `Frontend\odc-frontend`.

Q: How to run tests before presenting:
   - In the root folder run: `mvn test`
   - All 34 tests across all 8 microservices will run and report BUILD SUCCESS!
