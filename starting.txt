================================================================================
🚗✨ ON-DEMAND CAR WASH PLATFORM - SIMPLE STEP-BY-STEP STARTUP GUIDE (LOCALHOST)
================================================================================
This guide is written in plain, simple English so that ANYONE can extract this
project on any laptop and run the entire platform smoothly on localhost for
demonstrations to managers, evaluators, and teams.
================================================================================

--------------------------------------------------------------------------------
STEP 1: PREREQUISITES
--------------------------------------------------------------------------------
1. Java 21 (or later)
   Type:   java -version
   Check:  Should display version 21 (e.g., java version "21.0.6")

2. Node.js & npm (v20 or v22)
   Type:   node -v
   Type:   npm -v

*NOTE ABOUT MAVEN (mvn):*
You DO NOT need Maven installed globally! A lightweight Maven wrapper (`mvnw.cmd`)
is bundled right in the project root. `start-backend.bat` will automatically
detect and use `mvnw.cmd` if `mvn` is not on your PATH.

*NOTE ABOUT DATABASE & BROKER:*
You DO NOT need to install or configure MySQL or RabbitMQ for your demonstration!
All microservices come with zero-config in-memory database (H2) that seeds sample
packages, default accounts, and test data automatically on startup. RabbitMQ
event publishing is wrapped in safe try-catch blocks so services continue
smoothly even if RabbitMQ is not installed.


--------------------------------------------------------------------------------
STEP 2: HOW TO START THE PLATFORM (EASIEST 1-CLICK METHOD)
--------------------------------------------------------------------------------
In the extracted project folder, we have created two double-clickable scripts:

1. Double-click "start-backend.bat"
   - It will open separate terminal windows for all 8 microservices in the
     correct order (Eureka Server first, then Gateway, then all services).
   - If Maven is not installed in your PATH, it will automatically use `mvnw.cmd`.
   - Wait about 30-40 seconds for all services to start and register with Eureka.

2. Double-click "start-frontend.bat"
   - It starts the Angular frontend on http://localhost:4200.

3. Open your browser and go to:
   👉 http://localhost:4200


--------------------------------------------------------------------------------
STEP 3: ALTERNATIVE STARTUP METHODS (For Corporate Laptops)
--------------------------------------------------------------------------------
Method A: Using IntelliJ IDEA / Eclipse (Most Common & Recommended)
   1. Open the project folder in IntelliJ IDEA.
   2. Allow IntelliJ to sync the Maven projects (it uses its bundled Maven).
   3. Open and run each `@SpringBootApplication` main class in this order:
      - `EurekaServerApplication` (port 8761)
      - `ApiGatewayApplication` (port 8080)
      - `UserServiceApplication` (port 8081)
      - `BookingServiceApplication` (port 8083)
      - `PaymentServiceApplication` (port 8084)
      - `ReviewServiceApplication` (port 8085)
      - `NotificationServiceApplication` (port 8086)
      - `AdminServiceApplication` (port 8082)
   4. For Frontend, open a terminal in `Frontend\odc-frontend` and run:
      `npm start`

Method B: Manual Terminal using mvnw.cmd (if 'mvn' is not recognized)
   Instead of `mvn spring-boot:run`, run:
   `..\mvnw.cmd spring-boot:run` from each microservice directory.


--------------------------------------------------------------------------------
STEP 4: HOW TO CONNECT LOCAL MYSQL & RABBITMQ (OPTIONAL)
--------------------------------------------------------------------------------
If you want to demonstrate connecting to a real local MySQL database or
local RabbitMQ instance on your laptop:

A. CONNECTING LOCAL MYSQL (Port 3306):
   1. Ensure your local MySQL server is running (e.g., MySQL Workbench / Service).
   2. Log into MySQL and run:
      CREATE DATABASE carwash_db;
   3. In the project root, create a file named `.env` (or copy `.env.example` to `.env`).
   4. Put your MySQL credentials in `.env`:
      DB_URL=jdbc:mysql://localhost:3306/carwash_db?createDatabaseIfNotExist=true&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
      DB_DRIVER=com.mysql.cj.jdbc.Driver
      DB_DIALECT=org.hibernate.dialect.MySQLDialect
      DB_USERNAME=root
      DB_PASSWORD=your_mysql_password
   5. Restart backend services. Hibernate will automatically create all tables
      and the application will seed the catalogs into MySQL!

B. CONNECTING LOCAL RABBITMQ (Port 5672):
   1. Start your local RabbitMQ server on Windows.
   2. Default settings in each service already point to `localhost:5672` with
      username `guest` and password `guest`.
   3. No `.env` changes are required for default RabbitMQ!
   4. Microservices will now send real asynchronous AMQP messages across
      Booking, Notification, and Admin services.

To present to your manager, show this smooth end-to-end flow:

     ₹1499, Ceramic Pro ₹2999), 3-step workflow, and verified reviews.

2. STEP 1: CUSTOMER BOOKS A WASH

   - Click "✔ Complete Wash" (status changes to COMPLETED).
   - Click "Sign Out".

5. STEP 4: CUSTOMER PAYS WITH RAZORPAY & LEAVES A REVIEW

   - Complete payment: the booking instantly changes to "PAID" with a green badge!
   - Click "⭐ Rate & Review": submit 5 stars and comments.
   - Check the notification bell at the top right: all real-time events logged!
